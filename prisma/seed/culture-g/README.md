# Contenu du module Culture générale

Repris du dépôt `p4v1c/culture-g`, sans retouche : 14 sujets, 2 002 questions
et 238 leçons.

    *.json        un fichier par sujet — questions libres
    lecons/       un dossier par sujet, une leçon par fichier
    visuels/      les images, en data-URI ; référencées par leur slug

La traduction vers le format du moteur a lieu dans
`src/modules/culture-g/contenu.ts`, pas ici : ces fichiers restent la source,
et peuvent être remis à jour depuis le dépôt d'origine par une simple copie.
